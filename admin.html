Google Sheets Integration

Connect CL'S Brownies directly to a live Google Sheet. Customer orders placed on the website will be logged instantly in the spreadsheet, and this dashboard will stay in two-way sync.

Must be deployed as Web App with access set to "Anyone".

2-Minute Google Sheets Setup

  1. Create a blank spreadsheet at sheets.new.
  2. In the menu, open Extensions > Apps Script.
  3. Paste the code from google-apps-script.js (click button below to copy).
  4. Click Deploy > New deployment, select Web app, set Who has access to Anyone, then click Deploy.
  5. Copy your generated Web App URL and paste it into the field above!
